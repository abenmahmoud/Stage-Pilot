# Checklist qualité - Centre de communication

- [x] Le besoin distingue publication web, diffusion et réponses.
- [x] Le contenu public et le contenu interne sont séparés.
- [x] Une validation humaine précède toute action officielle.
- [x] La liste des destinataires n'est jamais rendue au navigateur.
- [x] Les emails sont individuels et les réponses ne repartent pas à la liste.
- [x] Les pannes, doublons, reprises et corrections sont définis.
- [x] Le Webmail reste une application séparée.
- [x] Le fonctionnement sans IA est conservé.
- [x] Aucun secret, contact réel ou pièce jointe n'est placé dans la spec.
- [x] Les Hebdos personnels sont internes par défaut et jamais publics sans
  confirmation.
- [x] Les rôles reprennent le circuit validé du module de contenus.
- [ ] Les mentions et durées de conservation sont validées avec la direction.
