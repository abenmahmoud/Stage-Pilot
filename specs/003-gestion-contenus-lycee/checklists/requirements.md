# Checklist qualité de la spécification

- [x] Le besoin hebdomadaire et les utilisateurs sont explicités.
- [x] La V1 est séparée des améliorations futures.
- [x] Les droits de publication sont distincts de l'édition.
- [x] L'IA ne publie jamais et ne reçoit pas les documents bruts.
- [x] Les brouillons et fichiers restent privés.
- [x] Les versions, l'archivage et l'expiration sont prévus.
- [x] Le public ne dépend pas d'un accès direct aux tables internes.
- [x] Les critères d'acceptation sont vérifiables.
