# Brief Claude - retrait des brouillons agent

## État

Préparé mais non exécuté. Le modèle Claude exact et le plafond de jetons propres
à cette mission ne sont pas définis. Aucun quota externe ne doit être consommé
sans ces paramètres, même si des audits réguliers ont été demandés.

## Mission proposée

- Lecture seule, sans commande, réseau, modification ni déploiement.
- Périmètre : route agent de fichier, route de réponse, détail agent, composant
  React, CSS, test ciblé et documentation opérationnelle.
- Limite de jetons : à confirmer par le propriétaire.
- Livrable : un rapport unique, classé par sévérité.

## Questions

1. Une course retrait/envoi peut-elle supprimer un document déjà publié ?
2. Un agent global peut-il retirer le brouillon d'un autre compte ou service ?
3. Un contrôle antivirus en cours peut-il être interrompu et polluer la file ?
4. Un échec Storage peut-il laisser la base annoncer un retrait réussi ?
5. L'audit, les erreurs ou l'interface révèlent-ils un nom ou un chemin privé ?
6. Les méthodes, limites de débit et validations client/serveur sont-elles
   contournables ?

Toute conclusion externe devra être reproduite localement avant correction.
