# Corps du registre de connaissances bornés - preview

- Création et modification d'une compétence : 64 Ko maximum.
- Preuve d'évaluation : 32 Ko maximum.
- Réservation d'un document : 16 Ko de métadonnées maximum.
- Actions de version, de source et revue documentaire : 4 Ko maximum.
- Confirmation du dépôt : aucun payload accepté.
- Le document de 50 Mo maximum est envoyé directement au stockage privé signé.
- Le test permanent couvre les huit routes sans compte ni base distante.
